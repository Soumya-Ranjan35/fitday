# FitDay — Angular daily planner

A responsive beginner-friendly daily to-do and home-exercise tracker built with standalone Angular components.

## Features
- Daily to-do list: add, complete, categorize and delete tasks
- Beginner home workout checklist with exercise instructions and durations
- Daily progress indicators
- Previous/next day navigation
- Progress saved in browser localStorage separately for each date
- Responsive layout for mobile and desktop

## Run locally
1. Install Node.js (LTS).
2. Extract this project.
3. In the project folder, run:

   ```bash
   npm install
   npm start
   ```

4. Open the local URL printed by Angular CLI (usually http://localhost:4200).

## Build
```bash
npm run build
```

## Notes
- This is a front-end starter app; it does not require a backend or account.
- Data is stored in the current browser on the current device. Clearing browser storage will clear saved progress.
- Exercise suggestions are general beginner examples, not medical advice. Start gently and stop if you feel pain, dizziness or unusual shortness of breath.
